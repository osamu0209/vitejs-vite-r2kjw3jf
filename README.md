# ぶたさんフリック！

## StackBlitzでの起動
1. StackBlitzで「Vite + React + TypeScript」プロジェクトを新規作成。
2. `src/App.tsx` と `src/App.css` をこのZIP内の同名ファイルで置き換え。
3. `src/main.tsx` も置き換え。
4. `package.json`、`tsconfig.json`、`vite.config.ts`、`index.html` をルートに配置。
5. 依存関係のインストール後、`npm run dev`（StackBlitzでは通常自動起動）。

## ゲーム仕様
- 60秒制限。豚は左右に往復しながら上下にふわふわ移動。
- 食材を選んでゲーム画面をタップ／クリックすると豚に向かって投げます。
- 食材は得点が高いほど低確率になる重み付き抽選。肉は1プレイ最大5回。
- 得点：肉-100、魚+10、野菜+5、ご飯+20、カレー+50、スイーツ+100、豆腐-2、納豆-5。

## 調整ポイント
`src/App.tsx` の `FOODS` にある `weight` が出現率の比率です（肉以外）。`pickFood` 内の `0.065` が肉の抽選確率です。肉は残数が5回に達すると出なくなります。

※ 現状は絵文字を使った簡素なプロトタイプです。実機での操作感や投げる軌道は、StackBlitz上で動かしながら調整できます。
